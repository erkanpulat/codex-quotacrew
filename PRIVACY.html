Your data and the application's purpose

QuotaCrew is an independent local utility for managing Codex accounts, viewing usage quotas and tracking local conversations. It is not an OpenAI product. Contact the maintainer at destekdryapp@gmail.com.

Saved account labels, account identifiers, selected settings, quota observations and local conversation information are stored in a local SQLite database. This includes conversation titles, preview snippets, workspace paths and goal notes you save locally; these fields can contain text from your conversations. Verified email addresses are held in memory for optional display. QuotaCrew reads local Codex conversation information to show jobs and, when you enable continuation, to check whether an interrupted conversation can continue. Full conversation bodies read for these checks are processed in memory and are not stored by QuotaCrew; the listed cached fields remain until their records or the retained application data are removed.

Sign-in credentials and protection

Sign-in takes place through Codex and OpenAI in your browser. QuotaCrew keeps copies of Codex sign-in files in managed account directories. Switching an account replaces the shared Codex sign-in file and can restart Codex Desktop. A temporary recovery snapshot contains the previous sign-in and configuration so an interrupted switch can be rolled back.

On Windows, QuotaCrew encrypts its saved profile credentials and account-switch recovery snapshots with user-scoped Windows DPAPI, in addition to restricted file permissions. Managed profiles are temporarily decrypted for the official Codex process; the latest token is encrypted again after that process stops. A forced application or system crash can leave a restricted plaintext working file until QuotaCrew next starts and seals it. Data cannot normally be decrypted by a different Windows user; moving to another PC or losing the original user keys may require signing in again.

The active shared Codex auth.json remains in Codex's plaintext file format for compatibility. QuotaCrew restricts its writes to that file to the current Windows user. The application-owned data directories have current-user-only Windows access permissions inherited by new files, including SQLite sidecars. Existing database files and sidecars are also restricted at startup. Codex sign-in credentials are stored separately from SQLite. The local SQLite database and its backups are not encrypted by QuotaCrew; cached metadata and goal notes can contain sensitive text supplied in conversations or notes. File permissions do not prevent a Windows administrator from taking ownership. Same-user malware can invoke DPAPI or read credentials while they are in use. Non-Windows source installations use file permissions and do not provide this Windows encryption. Log text is redacted to remove recognized token and email patterns, but redaction is not a guarantee that all upstream text is safe.

Network connections and third parties

QuotaCrew does not run a telemetry or credential-proxy service and does not upload your saved accounts to a publisher-operated server. Codex connects to OpenAI for sign-in, account status and model work. When automatic continuation is enabled and its checks pass, QuotaCrew sends a continuation request to your existing Codex conversation. This can start model work and consume your plan's quota.

Direct-download installations may check the public GitHub release API daily when enabled. The check sends an application-version User-Agent; it does not include account tokens, account labels or conversation content. Downloading an update contacts GitHub's release hosting. MSIX installations use Microsoft Store for application updates. If you choose to install a missing Codex CLI, the utility downloads and executes OpenAI's official Windows installer after separate confirmation; that installer manages its own files and PATH changes.

OpenAI, Microsoft and GitHub process their service connections under their own privacy policies. Opening public support links or emailing the maintainer shares the information you choose to provide and the connection information required by those services. Never include sign-in files or tokens in support messages.

Your controls and retention

You can pause monitoring, choose the account-switching policy, disable automatic continuation, hide displayed emails and change update-check preferences in the application. MSIX update preferences are managed in Microsoft Store. Continuing in the tray and starting with Windows are separate choices. Shutdown plans require confirmation for each session and are cancelled when the application exits.

Removing a saved account with its files deletes that managed profile. It does not necessarily sign you out of the shared Codex session; use Codex's sign-out controls for that session. Clearing tracking removes QuotaCrew's tracking records and pauses its monitoring without deleting shared Codex conversations. Recovery snapshots are removed after a completed switch or successful rollback. Event history keeps up to 10,000 events; update database backups keep the two newest files. Other saved application data remains until you remove it.

Application removal preserves the shared ~/.codex history and the application's shared data directory, %LOCALAPPDATA%\CodexAccountManager, so reinstallation does not silently destroy accounts. To erase QuotaCrew's retained data, close it and remove its data directory after reviewing any backups you want to keep. Other Codex installations and cloud data are controlled by Codex and OpenAI.

Removing retained local data

  1. Finish or cancel account sign-in and CLI installation. Exit QuotaCrew from its tray menu and close any terminals using its managed profiles. Uninstall QuotaCrew through Windows Settings → Apps. Uninstalling alone preserves the data described above.
  2. In File Explorer, enter %LOCALAPPDATA%. Delete the CodexAccountManager folder, including profiles, accounts.db and its sidecars, backups, logs, recovery files and any old updates files. This removes all application-owned saved accounts, preferences and tracking records. Empty the Recycle Bin for these items if you want them removed from Windows' normal recovery flow. Remove any backups or diagnostic exports you copied elsewhere separately.
  3. The active sign-in and conversation history in %USERPROFILE%\.codex belong to the independent Codex clients. Sign out through each client's controls if you also want to end those sessions. Deleting QuotaCrew's data does not sign those clients out or erase OpenAI cloud data. Do not delete the whole .codex folder just to remove QuotaCrew; it contains your Codex conversations and other client data.
  4. The optional official Codex CLI installation is separate and remains after uninstall. If no other application needs it, close Codex processes and remove its standalone files under %LOCALAPPDATA%\Programs\OpenAI\Codex and, for the current installer layout, %USERPROFILE%\.codex\packages\standalone. Check your actual installation first: other installation methods can use different paths. In Windows' user environment-variable editor, remove only %LOCALAPPDATA%\Programs\OpenAI\Codex\bin from the user Path value under HKEY_CURRENT_USER\Environment; preserve every other entry. Removing the CLI also affects other applications that use it.
  5. Delete the optional QuotaCrew desktop shortcut if you created one. Microsoft manages Store startup-task registration with the package.

These steps remove local files logically. They cannot guarantee forensic erasure from disks or deletion of copies retained by your backup or sync services; manage those copies through the relevant service.

Diagnostics and policy changes

Diagnostic exports contain allowed check names and results, the CLI version and profile count. They exclude credentials, the account database, raw logs, account labels, personal paths and conversation content. Exports are created locally; sharing them is your choice. This policy will be updated when the application's data handling changes.

QuotaCrew gizlilik politikası

Verileriniz ve uygulamanın amacı

QuotaCrew; Codex hesaplarını yönetmek, kullanım kotalarını görmek ve yerel konuşmaları takip etmek için bağımsız bir yerel araçtır. OpenAI ürünü değildir. Bakım sorumlusuna destekdryapp@gmail.com adresinden ulaşabilirsiniz.

Kaydedilen hesap adları, hesap kimlikleri, tercihler, kota gözlemleri ve yerel konuşma bilgileri SQLite veritabanında tutulur. Bunlar konuşma başlıklarını, kısa önizleme metinlerini, çalışma klasörü yollarını ve yerelde kaydettiğiniz hedef notlarını içerir; bu alanlarda konuşmalarınızdan metin bulunabilir. Doğrulanmış e-posta adresleri isteğe bağlı gösterim için bellekte tutulur. QuotaCrew işleri göstermek ve devam özelliğini açtığınızda kesilmiş konuşmanın devam edebilirliğini kontrol etmek için yerel Codex konuşma bilgilerini okur. Bu kontrollerde okunan tam konuşma gövdeleri bellekte işlenir ve QuotaCrew tarafından kaydedilmez; belirtilen önbellek alanları, kayıtları veya saklanan uygulama verileri kaldırılana kadar tutulur.

Giriş bilgileri ve koruma

Giriş, Codex ve OpenAI üzerinden tarayıcınızda yapılır. QuotaCrew Codex giriş dosyalarının kopyalarını yönetilen hesap klasörlerinde tutar. Hesap geçişi ortak Codex giriş dosyasını değiştirir ve Codex Desktop'ı yeniden başlatabilir. Kesilen bir geçişin geri alınabilmesi için önceki giriş ve yapılandırma bilgileri geçici kurtarma kaydında bulunur.

Windows'ta QuotaCrew, kaydettiği profil giriş bilgilerini ve hesap geçişi kurtarma kayıtlarını kullanıcıya bağlı Windows DPAPI ile şifreler; dosya erişim izinlerini de sınırlar. Yönetilen profil, resmî Codex süreci çalışırken geçici olarak çözülür; süreç durduktan sonra en güncel token yeniden şifrelenir. Uygulamanın veya sistemin zorla kapanması, QuotaCrew tekrar açılıp dosyayı şifreleyene kadar kısıtlı erişimli açık bir çalışma dosyası bırakabilir. Farklı Windows kullanıcısı bu veriyi normalde çözemez; bilgisayar değiştirilmesi veya özgün kullanıcı anahtarlarının kaybı yeniden giriş gerektirebilir.

Etkin ortak Codex auth.json dosyası, Codex ile uyumluluk için düz metin biçiminde kalır. QuotaCrew bu dosyaya yaptığı yazmalarda erişimi mevcut Windows kullanıcısıyla sınırlar. Uygulamanın kendi veri klasörleri yalnızca mevcut kullanıcıya erişim izni verir; SQLite yan dosyaları dahil yeni dosyalar bu izinleri devralır. Var olan veritabanı ve yan dosyalarının izinleri de başlangıçta sınırlandırılır. Codex giriş bilgileri SQLite'tan ayrı saklanır. Yerel SQLite veritabanı ve yedekleri QuotaCrew tarafından şifrelenmez; önbellekteki bilgiler ve hedef notları, konuşmalarınızda veya notlarınızda sağladığınız hassas metinleri içerebilir. Dosya izinleri, Windows yöneticisinin sahipliği devralmasını engellemez. Aynı kullanıcı yetkisiyle çalışan zararlı yazılım DPAPI'yi çağırabilir veya kullanım sırasındaki giriş bilgilerini okuyabilir. Windows dışındaki kaynak kurulumları dosya izinleri kullanır, bu Windows şifrelemesini sağlamaz. Loglarda tanınan token ve e-posta örüntüleri gizlenir; bu filtre, dışarıdan gelen her metnin güvenli olduğu garantisini vermez.

Ağ bağlantıları ve üçüncü taraflar

QuotaCrew telemetri veya giriş bilgisi aracı servisi işletmez; kayıtlı hesaplarınızı yayıncının sunucusuna yüklemez. Codex giriş, hesap durumu ve model çalışmaları için OpenAI'a bağlanır. Otomatik devam açıkken ve kontrolleri başarılı olduğunda, QuotaCrew mevcut Codex konuşmanıza devam isteği gönderir. Bu işlem model çalıştırıp plan kotanızı tüketebilir.

Doğrudan indirilen kurulumlar, tercih açıksa GitHub'ın herkese açık sürüm API'sini günde bir kontrol edebilir. Kontrolde uygulama sürümünü belirten User-Agent gönderilir; hesap token'ları, hesap adları ve konuşma içeriği gönderilmez. Güncelleme indirme GitHub sürüm sunucularına bağlanır. MSIX kurulumları uygulama güncellemeleri için Microsoft Store'u kullanır. Eksik Codex CLI'yi kurmayı seçerseniz araç, ayrı onayınızın ardından OpenAI'ın resmî Windows kurulum betiğini indirip çalıştırır; bu kurulum kendi dosyalarını ve PATH değişikliğini yönetir.

OpenAI, Microsoft ve GitHub servis bağlantılarını kendi gizlilik politikalarına göre işler. Destek bağlantısı açmanız veya bakım sorumlusuna e-posta göndermeniz, seçtiğiniz bilgileri ve o servislerin bağlantı için ihtiyaç duyduğu bilgileri paylaşır. Destek mesajlarına giriş dosyası veya token eklemeyin.

Kontrolleriniz ve saklama süresi

Uygulamadan izlemeyi duraklatabilir, hesap geçiş politikasını seçebilir, otomatik devamı kapatabilir, e-postaları gizleyebilir ve güncelleme kontrol tercihini değiştirebilirsiniz. MSIX güncelleme tercihleri Microsoft Store'dan yönetilir. Tepside çalışma ve Windows ile başlatma ayrı tercihlerdir. Kapatma planları her oturumda onay gerektirir; uygulamadan çıkınca iptal edilir.

Bir hesabı dosyalarıyla kaldırmak yönetilen profili siler. Bu, ortak Codex oturumundan çıkış anlamına gelmeyebilir; o oturum için Codex'in çıkış kontrollerini kullanın. Takibi temizlemek QuotaCrew takip kayıtlarını silip izlemeyi duraklatır; ortak Codex konuşmalarını silmez. Kurtarma kaydı başarılı geçiş veya geri alma sonrası silinir. Etkinlik geçmişi en fazla 10.000 kayıt, güncelleme veritabanı yedekleri en yeni iki dosya tutar. Diğer kayıtlı uygulama verileri siz kaldırana kadar kalır.

Uygulamayı kaldırmak ortak ~/.codex geçmişini ve %LOCALAPPDATA%\CodexAccountManager veri klasörünü korur; yeniden kurulum hesapları sessizce silmez. QuotaCrew verilerini tamamen silmek için uygulamayı kapatıp saklamak istediğiniz yedekleri kontrol ettikten sonra kendi veri klasörünü kaldırın. Diğer Codex kurulumları ve bulut verileri Codex ve OpenAI tarafından yönetilir.

Saklanan yerel verileri silme

  1. Hesap girişi ve CLI kurulumunu tamamlayın veya iptal edin. Tepsi menüsünden QuotaCrew'den çıkın; yönetilen profilleri kullanan terminalleri kapatın. Windows Ayarlar → Uygulamalar bölümünden QuotaCrew'ü kaldırın. Yalnızca kaldırmak yukarıda belirtilen verileri silmez.
  2. Dosya Gezgini'ne %LOCALAPPDATA% yazın. CodexAccountManager klasörünü; profiles, accounts.db ve yan dosyaları, backups, logs, kurtarma dosyaları ve eski updates dosyalarıyla birlikte silin. Uygulamanın kaydettiği tüm hesaplar, tercihler ve takip kayıtları kaldırılır. Windows'un normal geri yükleme olanağından da kaldırmak isterseniz bu öğeleri Geri Dönüşüm Kutusu'ndan silin. Başka yere kopyaladığınız yedekleri veya tanılama dosyalarını ayrıca kaldırın.
  3. %USERPROFILE%\.codex içindeki etkin giriş ve konuşma geçmişi, bağımsız Codex uygulamalarına aittir. O oturumları da sonlandırmak için her uygulamanın çıkış kontrollerini kullanın. QuotaCrew verilerini silmek bu uygulamalardan çıkış yapmaz veya OpenAI bulut verilerini silmez. Yalnızca QuotaCrew'ü kaldırmak için tüm .codex klasörünü silmeyin; bu klasör Codex konuşmalarınızı ve diğer istemci verilerini içerir.
  4. İsteğe bağlı resmî Codex CLI kurulumu ayrıdır ve kaldırma sonrası kalır. Başka uygulama kullanmıyorsa Codex süreçlerini kapatıp %LOCALAPPDATA%\Programs\OpenAI\Codex altındaki bağımsız CLI dosyalarını ve güncel yükleyici düzeninde %USERPROFILE%\.codex\packages\standalone klasörünü kaldırın. Önce gerçek kurulumunuzu kontrol edin; farklı kurulum yöntemleri farklı yollar kullanabilir. Windows'un kullanıcı ortam değişkenleri düzenleyicisinde, HKEY_CURRENT_USER\Environment altındaki kullanıcı Path değerinden yalnızca %LOCALAPPDATA%\Programs\OpenAI\Codex\bin girdisini çıkarın; diğer girdileri koruyun. CLI'yi kaldırmak onu kullanan diğer uygulamaları da etkiler.
  5. Oluşturduysanız isteğe bağlı QuotaCrew masaüstü kısayolunu silin. Store başlangıç görevi kaydını Microsoft paketle birlikte yönetir.

Bu adımlar yerel dosyaları mantıksal olarak kaldırır. Disklerden adli düzeyde silinmeyi veya yedekleme/senkronizasyon servislerinin sakladığı kopyaların silinmesini garanti etmez; bu kopyaları ilgili servisten yönetin.
